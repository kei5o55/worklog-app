## Rough Cut（仮称）

創作活動向けの作業ログ・タイマーアプリ。
作業時間・コミット・制作過程・納期・メモをプロジェクト単位で記録できます。

主に創作活動を想定していますが、イラスト制作・音楽制作・プログラミング・勉強など
様々な作業の記録ツールとして利用できます。

**DEMO:**
https://worklog-app-ruby.vercel.app/projects

## コンセプト

本アプリは「作業の可視化」を目的としたツールです。

タイマーによる作業記録とログ管理を組み合わせることで、
日々の作業量や継続状況を振り返ることができます。

使用機器を問わないwebアプリケーションとして開発することで、
- デジタル環境ではイラストの保存データを添付
- アナログ環境ではスマホで撮影した写真を添付

のように様々な創作活動に活用できるツールを目指しています。

## 開発背景

Githubを用いた開発を行っていると、コミット履歴のように何をどれくらい作業したのかを振り替えられる体験に価値を感じていました。
一方、イラスト制作などの創作活動では作業ログが残りにくく、継続のモチベーション管理が難しい場面があります。
そのため

- 作業時間を自然に記録できる
- プロジェクト単位で作業履歴を残せる
- 見返した際の達成感を次の活動に活かせる

ツールとして本アプリを開発しています。

また、ラフ段階から完成までの履歴を時系列で残せることで、
生成AIが普及した現代において、人が積み重ねて制作した記録を残す役割も持てるのではないかと考えています。


## 設計思想

本アプリでは「作業ログを自然に蓄積する」ことを重視しています。

そのため

- タイマー停止時にコミットを促す
- 作業単位をプロジェクトに紐付ける

など、作業フローを崩さない設計を意識しました。

タイマー起動 → 作業 → タイマーストップ（保存）

のように単純な操作でプロジェクトの進行を記録でき、プロジェクトごとに振り替えることが可能です。

コミットごとに画像の添付やコメントを残すことができ、長期的な創作活動の過程そのものを蓄積できる仕組みを目指しています。

## 使用技術
- **TypeScript**
  - 静的型付けによる安全性の高い実装を行い バグの抑制および保守性・拡張性を意識した設計を実施
- **React**
  - コンポーネント指向に基づく画面構成を採用し，UIの再利用性と拡張性を考慮した実装
- **Vite（Next.jsを用いた環境へ移行中）**
  - 開発当初はViteのみを使用、ミニマルに制作していましたが、アプリ規模の拡大に伴いNext.js環境へ移行中。
  - 他プロジェクトでApp Router/レイアウト管理などの利点を感じたことも移行理由の一つ
- **tailwind css**
  - コードとして可読性の高いUI設計として使用
- **React Router**
- **IndexedDB**
  - 画像を保存する形式のため、localstorageよりも大容量を扱えるIndexedDBを採用
  - 将来的にはサーバサイドDBへの同期を行い、複数端末での管理が可能な構成へ拡張が出来たら面白いのではないかとも考えています。

## 機能一覧（現時点）

**1. プロジェクト管理**

- 新規プロジェクト作成（モーダル）
  - 名前（必須）
  - 納期（任意）
  - メモ（任意）
  - ポモドーロ作業時間（任意）
  - 休憩時間（任意）
- 一覧表示
- 削除（confirmあり）
- Contextでアプリ全体共有
